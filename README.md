# Zwits Services

Build a modern mobile-first marketplace platform called Zwits.



Zwits connects customers with trusted service providers for deliveries, transport, repairs, cleaning, farming services, beauty services, freelance services, and emergency help.



The platform must include:



1. Customer App

- Registration/login

- Service booking

- Live tracking

- Ratings/reviews

- Payment integration

- Notifications

- Job history



2. Service Provider Dashboard

- Profile management

- Accept/reject jobs

- Earnings dashboard

- Availability toggle

- Ratings

- GPS tracking



3. Admin Dashboard

- User management

- Provider verification

- Analytics

- Commission management

- Dispute handling



4. Website Pages

- Home

- About

- Services

- Contact

- Become a Provider

- FAQ

- Privacy Policy

- Terms



5. Tech Stack

- Next.js

- React

- Tailwind CSS

- Supabase backend



6. Integrations

- Google Maps or Mapbox

- EcoCash

- InnBucks

- Visa/Mastercard payments



7. Design Style

- Modern African startup

- Clean UI

- Black, white, orange, gold theme

- Mobile-first Android optimized



8. Core Business Logic

- Customers book services

- Providers accept jobs

- Zwits takes commission from transactions

- Ratings and verification systems included



Create responsive UI, database schema, authentication flow, dashboards, and booking system.
