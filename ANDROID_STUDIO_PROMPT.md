You are working inside an existing **Capacitor 8 Android project** generated by
`npx cap add android`. Do NOT create a new app, do NOT convert it to Jetpack

is asked. All UI is a web app rendered in the Capacitor WebView.

## Context

- The app is a WebView shell for the Zwits marketplace (Zimbabwe: services,
  bookings, deliveries). The web app is server-rendered, so there is **no
  bundled `index.html`** — Capacitor loads a remote URL from `capacitor.config.json`:
  - Customer → `https://zwits.co.zw/m/customer`, appId `zw.co.zwits.customer`, app name "Zwits"
  - Provider → `https://zwits.co.zw/m/provider`, appId `zw.co.zwits.provider`, app name "Zwits Provider"
  - Driver   → `https://zwits.co.zw/m/driver`, appId `zw.co.zwits.driver`, app name "Zwits Driver"
  - `server.allowNavigation` already permits `zwits.co.zw`, `www.zwits.co.zw`,
    `*.supabase.co`, `*.lovable.app`.
- Installed Capacitor plugins (their Gradle deps are auto-wired; only manifest
  permissions/config are your job): App, Camera, Filesystem, Geolocation,
  Haptics, Network, Preferences, Push Notifications, Splash Screen, Status Bar.
- Backend is Supabase (auth, storage, realtime) called from the web layer.
- Brand colors: green `#16A34A` (primary), blue `#2563EB` (secondary),
  black `#0B0F0D` (dark surfaces), light gray `#F5F7F6`.

## Tasks

1. **Manifest & permissions** — in `app/src/main/AndroidManifest.xml` add only
   what the plugins need: `INTERNET`, `ACCESS_FINE_LOCATION`,
   `ACCESS_COARSE_LOCATION`, `CAMERA`, `POST_NOTIFICATIONS` (API 33+),
   `READ_MEDIA_IMAGES` (API 33+) with legacy `READ_EXTERNAL_STORAGE`
   `maxSdkVersion="32"`, and the `FileProvider` entry required by
   `@capacitor/camera`. Add `android:usesCleartextTraffic="false"`.

2. **Deep links** — add intent filters on `MainActivity` for:
   - custom scheme `zwits://` (host `auth`) for Supabase OAuth/magic-link returns
   - Android App Links: `https://zwits.co.zw` + `https://www.zwits.co.zw`
     with `android:autoVerify="true"`, limited to the path prefix for this app
     variant (`/m/customer`, `/m/provider` or `/m/driver`).
   Explain what `assetlinks.json` must contain for verification.

3. **Push notifications (FCM)** — show exactly where to drop
   `app/google-services.json`, add the `com.google.gms.google-services` plugin
   and classpath to the Gradle files, and create a notification channel plus
   `<meta-data>` for the default channel, small icon (white-on-transparent) and
   the accent color `#16A34A`. Do not write custom `FirebaseMessagingService`
   logic — the Capacitor plugin handles delivery.

4. **Theming & splash** — set the status bar / navigation bar colors and the
   splash background to `#0B0F0D` (Provider) or `#2563EB` (Driver) or the
   config's value, and wire adaptive launcher icons in `res/mipmap-anydpi-v26`.
   Generate placeholder `ic_launcher_foreground` vector using the brand green.

5. **WebView behaviour** — in `MainActivity` (Kotlin), after `super.onCreate`,
   enable what the app needs without breaking Capacitor: DOM storage,
   `mediaPlaybackRequiresUserGesture = false`, and handle the hardware back
   button so it navigates the WebView history and only exits at the root.

6. **Build config** — target/compile SDK 35, minSdk 23, JDK 17. Add a
   `signingConfigs.release` block reading `keystore.properties` (never hardcode
   secrets), enable `minifyEnabled` + `shrinkResources` for release with a
   ProGuard rule keeping Capacitor and plugin classes, and set
   `versionCode`/`versionName`.

7. **Verify** — run a Gradle sync and `./gradlew assembleDebug`; fix any
   Manifest merger or dependency conflicts. Report each file you changed.

## Constraints

- Never edit files under `app/src/main/assets/` or `capacitor.config.json` —
  they are regenerated by `npx cap sync`.
- Do not add native screens, Retrofit, Room, or any Supabase Android SDK.
- Do not hardcode API keys, keystore passwords, or Supabase secrets.
- Keep every change compatible with re-running `npx cap sync android`.
